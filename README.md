# 토익 단어장 (700·800·900)

GitHub Pages로 배포하면 폰/PC에서 설치형 앱처럼 쓸 수 있습니다.

1. GitHub에서 새 저장소 생성 (예: toeic-vocab, Public)
2. 이 폴더의 파일 전부(index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png)를 저장소 루트에 업로드
3. Settings > Pages > Source: Deploy from a branch > main / (root) > Save
4. 1~2분 뒤 https://<내아이디>.github.io/toeic-vocab/ 접속
5. 설치: 안드로이드 Chrome은 메뉴 > 앱 설치, 아이폰 Safari는 공유 > 홈 화면에 추가
